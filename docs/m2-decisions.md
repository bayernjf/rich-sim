## D1 · F5 首个剧本身份 → 建议：**卡 A 科技独角兽创始人（新钱）**

`simulation-gameplay.md` §4.4 已定稿两张虚构卡，卡 A 的年成本画像是现成的：**$1,317,000/年**（豪宅 120,000 + 私人飞机 1,000,000 + 豪华车 17,000 + 大额弹性 120,000 + 私人医疗 30,000 + 高档餐饮 30,000）。

四条理由：

1. **与领钱方案形成精确对照**：$1,000,000 ÷ $1,317,000 = **0.76 年 ≈ 9 个月**。也就是「你领的一百万，撑不过他第一年」——这句不需要编，是两边数字直接相除，且是 `homepage-claim-experience.md` §2 那个「听着多、其实不够」命门的最短表达。
2. **自带第二个教学时刻**：§4.4 给了断裂开关——再加一艘超级游艇（+$5,400,000）→ 年成本 $6,717,000，一个剧本演示「持有即套牢」，不需要额外内容。
3. **合规面最窄**：卡 A/B 都标注「虚构角色，不代表任何真实人物」，不触碰名人 publicity rights（那是 §4 路径 B/C 的问题，deferred #5 主要卡在那边）。
4. **卡 B 张力更弱**：老钱继承人年成本仅 $380,000–407,000，对照 $1M 起始金是「够」的，恰好废掉第 1 条的对照效果。

**翻转条件**：若你认为目标用户更想看的不是炫富而是传承/防御型配置，则改卡 B——但要同时接受起始金对照失效，得另找那个落差数字。

选：**看见·资产可视化** + **感受·情绪与代价（账单日）** + **比较·落点衔接（换算器）**。后置：操作·决策模拟（购物）、经历·人生剧情、地位·特权体验。

**翻转条件**：若你判断「没有购物就没有留存」，那需要先有 D4 的读数支持，否则是拿最贵的一条路赌未验证的假设。

## D3 · F2「精细模型（逐项支出）」→ 建议：**不做，从 MVP 移出、降为 P2**

我先前把它归为「不需拍板的小缺口」，查了契约后确认那是错的（见 `handoff.md` B 组更正）。但两条可行路都不该现在走：

- **(a) 只拆展示、引擎不读**：`Profile.expense` 是单个数字（`packages/core/src/types.ts:27`），拆解结果不参与计算 → **用户会以为它参与了**。这是制造假精度，比不做更糟。
- **(b) 让逐项支出真进引擎**：要改冻结的 `types.ts` / `draft.ts`（`CONVENTIONS.md`：改契约 = 过闸门），并牵动 `project` / `gap` / `buildMilestones` 口径与 `assumptionsVersion`。

更关键的是方向冲突：`PRD.md` §3.2 Non-Goals 明写**「不做记账工具」**，而逐项支出正是记账的入口。F2 的验收是「≤4 项、每项有示例值、可随时修改重算」——它的价值就在少。

**建议动作**：把这条从 §8 F2 的正文移出，改记 P2 并注明「与 §3.2 冲突，需先重开 Non-Goal 讨论」。

**翻转条件**：若将来数据显示用户普遍在「月支出」这一项上填不出来（填了但不准），那说明单一数字确实不够，届时按 (b) 走契约流程。

## D4 · 账号体系是否立项 → 建议：**暂不立项，等一个方向性读数**

理由三条：

1. 立项会**推翻已拍板决策**（`handoff.md`「MVP 形态 = 无后端、方案存 localStorage」），这种反转应该由数据触发，不该由推测触发。
2. 无账号时确实测不了绝对值，但**方向可读**：CF Web Analytics 给 session 级趋势、`rich-sim:events:v1` 给同设备漏斗。口径限制已记在 `deferred-items.md` #4（同设备回访、系统性偏低、不得与将来有账号后的数字横比）。
3. 现在最贵的成本是 F5，不是账号。

**判据（拿到读数后）**：同设备 7 日回访 ≥ 15% → 回访动机真实存在，账号体系值得立项；< 5% → 问题不在缺账号，上了也没用。中间地带再看完成率。

**⚠️ 本条的前提**：以上全部依赖 `PUBLIC_CF_WEB_ANALYTICS_TOKEN`，而它 **2026-10-05 被决定暂缓**。暂缓期间 D4 与 D5 无法推进，会无限期悬着——这不是我推翻你的暂缓，是把依赖摆出来。

## D5 · 投资线 / 付费墙 / 支付渠道 → 建议：**三条一起押后，且押在 D4 之后**

- **投资线**：红线最集中处（不荐股、不出现标的名、不做"推荐配置"按钮），且没有读数无法判断它是加分还是稀释。见 `homepage-claim-experience.md` §7 P3。

**翻转条件**：若你决定先用「点击定价档 = 付费意愿代理指标」这条轻量路径，那 #3 可以提前拍，我可以把它写进 `comparison-converter.md` 同级的一份小方案里。
