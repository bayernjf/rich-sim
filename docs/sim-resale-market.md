# 二手变卖（Sim Resale）设计 · v1 · 2026-10-10

> 状态：**草案，待发起人过目**。给富豪商城加「卖出」：已持有资产可二手变卖，
> 账单消失 + 一次性回笼现金进 sim 账本。与账单日组成完整闭环：
> **买 → 账单涨 → 负担率变红 → 卖 → 账单落、现金回血**。

## 1. 为什么做

「持有成本」教育目前只走到「账单变红 + 提示可以变卖」，提示不能点。
用户提议的「卖二手」让提示变成动作——卖出那一刻的解脱感，就是
「持有即开销」最直白的体感。红区 75% 折价口径（`RESALE_RECOVERY_RATE`）
与 `resaleRecovery()` 已在 core 冻结，本设计零新增算术。

明确不做「股票式交易市场」（个股/行情/挂单）：踩「不荐股、不推荐具体
金融产品」红线，且行情数值无来源。投资线的「自填收益率 + 蒙特卡洛
随机模拟（常驻非预测标注）」就是合规替代形态，不在本文档范围。

## 2. 口径决策（先拍这条）

**卖出回笼 = 该项 `annualCost` × 75%，显式标注「教学示意口径」。**

候选与取舍：

| 候选 | 结论 | 理由 |
|---|---|---|
| (a) `purchasePrice` × 75%（游艇 = $280M × 75% = $210M） | **否决** | 既有简化是「加购不扣本金」（卡 A 领 $1M 也能把 $280M 游艇加入账单——本模拟教的是持有成本，不是购买力）。买时不付钱、卖时拿 $210M = 凭空造钱，「够撑多久」直接失效 |
| (b) `annualCost` × 75%（游艇 = $4.05M） | **采纳** | 与已上线的红区变卖提示（$4,050,000，冒烟已钉住）同口径；语义 = 租约转让 / 折旧残值的一次性回收，**不是资产本金**；金额量级对 $1M 起始金有感 |
| (c) 回笼 0，只消账单 | 否决 | 「卖二手没钱拿」与用户预期冲突，爽感没了 |

**顺手要修的一处不一致**：`mall.resellable` 文案写「只回笼原价的 {rate}」，
而现价计算用的是 `annualCost`——文案「原价」与计算口径不符，S1 一并改为
「年成本口径的 {rate}（教学示意）」。

## 3. 交互与 UI

- **入口**：购物车抽屉内，每个 `kind = asset | consumer` 且 `resellable !== false`
  的已持有项多出「卖出」按钮（`data-mall-sell`）；卡片网格不动。
- **体验类不可卖**：`resellable: false` 的两项（Met Gala 门票、环球之旅）不显示
  卖出按钮，改显一行灰字「体验无法转卖——这本身就是一课」（`mall.noResale`）。
- **卖出动作**（一键，无二段确认；可立即重新加购 = 事实上的撤销）：
  1. 从购物车移除该项 → 下一期账单与负担率即时回落（现有算术零改动）；
  2. 回笼金额 = `resaleRecovery(option.annualCost)` 累加进 sim 账本现金；
  3. 「够撑多久」分子 = `startingCapital + resaleProceeds`，月数即时变长；
  4. `aria-live` 播报「已卖出 {item}，回笼 {amount}」；埋点 `sim:sell` 零 props。
- **空车 / 全卖完**不报错，回到基态黄区（基线负担率 ≈78%）。

## 4. 账本与契约

- `SimState` 增**可选** `resaleProceeds?: number`（累计回笼，默认 0）——
  与 `cart` / `favorites` 同套路：`schemaVersion` 维持 1，旧草稿缺字段即 0，
  坏数据（负数/NaN）收敛为 0。进 `CONVENTIONS.md` 冻结表。
- 新纯函数 `sellCartItem(state, key)`：移除车项 + 累加回笼，一次写盘
  （`sim:sell` 与 `sim:remove` 各埋一条，语义分开）。
- **两本账红线**：`resaleProceeds` 永远留在 SIM；`adoptCartAsGoal`（SIM→REAL
  单向桥）只带年成本一个数字的现状不动，回笼现金不过桥。

## 5. 红线对照（逐条）

| 红线 | 本设计 |
|---|---|
| 不做投资建议 / 不推荐具体金融产品 | 卖出价 = 自有目录项的固定折价算术，无行情、无标的推荐 |
| 数值必须有来源或显式标注 | 75% 为既有冻结教学口径，卖出按钮旁与播报均带「教学示意」 |
| 不预测、不承诺结果 | 无价格涨跌——折价固定，不存在「低买高卖」叙事 |
| 用户财务数据不上传 | `sim:sell` 零 props |
| 两本账互不读写 | 见 §4 |

不做清单（明确排除）：讨价还价、二手行情、其他买家、卖出倒计时、
按持有时长折旧、消费税/手续费。

## 6. 分期

| 期 | 内容 | 工作量 |
|---|---|---|
| **S1** | `resaleProceeds` 账本字段 + `sellCartItem` + 抽屉卖出按钮/播报 + 「够撑多久」新分子 + `sim:sell` 埋点 + 文案口径修正 | S |
| **S2** | 冒烟迁移（卖出 → 账单落 → 月数变长全链路断言）+ DEPLOYMENT 事件清单 + handoff 回写 | S |

S1+S2 一次交付。后续若要「消费品折旧曲线」等增强，单列 P2。

## 7. 验收

1. 加购游艇 → 抽屉点「卖出」→ 车空、负担率回黄、「够撑多久」分子 +$4,050,000
2. Met Gala 项无卖出按钮、显示不可转卖说明
3. 刷新页面后 `resaleProceeds` 仍在（持久化）；清 sim 账本归零
4. `adoptCartAsGoal` 结果页 goalOverride 不含回笼现金
5. 冒烟：`sim:sell` 入队、月数变长、体验项无按钮；既有断言不红
