# 财富模拟（rich-sim）— 产品构想与验证文档

> 状态：构想阶段，核心假设**均未验证**。
> 本文档 = 原始构想存档 + 独立评估 + 建议方向 + 最小验证计划。
> **产品名已定（2026-10-03）：rich-sim，中文名「财富模拟」。** §7.2 保留原候选名存档。

---

## 1. 一句话定位

**帮用户看清"我的钱到底能买到什么样的生活，以及差多远"的沉浸式财务模拟器。**

- 表面是"体验不同财富水平的人生"，内核是个人财务对标与目标规划。
- 差异化：市面要么是纯娱乐的财富模拟游戏（与真实财务无关），要么是枯燥的记账/理财工具（无体验、无目标感）。本产品把二者缝在一起。

> 注意：这个定位已经是对原始构想的**收窄**。原始构想叫"幻想财富 / 富人模拟"，本方案建议把外壳从"扮演富豪"换成"设计理想生活"——理由见 §4。**2026-10-03 已确认方向**：采用「双主线」折中方案——保留富豪模拟作为钩子，落点仍是用户自己的现实目标。见 §4 与 §7.1。

## 2. 原始构想存档

以下是发起时的完整构想，保留备查。完整原始对话（逐字）见 [original-qa.md](./original-qa.md)。

### 2.1 两大模块

**A. 幻想体验层（沉浸、财富可视化）**

1. **资产可视化面板**：不写干巴巴的数字，而是拆成房产 / 股权 / 基金 / 豪车 / 艺术品 / 现金流，可交互查看。每项资产附带**持续消耗项**（月供、维护、物业、税费、佣人开销、私人飞机年持有成本）——刻意打破"有钱就没有开销"的错觉。
2. **人生模拟体验**：可选身份（互联网创始人 / 地产投资人 / 家族信托持有者 / 天使投资人）。模拟买豪宅、配资产、缴税、投资、现金流波动（含亏损、行业下行）。虚拟身份有**真实资产负债表**，会现金流断裂，不是无限钱。
3. **沉浸式场景**：2D / 简易 3D 切换住所、办公室、旅行场景，生活质量随资产变动。

**B. 现实对标 & 规划层（产品核心价值）**

1. **对标测算**：用户录入真实收入、存款、负债、固定开支；系统对比虚拟富人的年净现金流 / 总资产 vs 用户当前储蓄率 / 资产增速，算出"按你现在速度要多少年达到该级别"，并标注前提假设（通胀、收益率、收入涨幅、无大额意外）与免责声明。
2. **阶梯目标计划**：拆成阶段目标（如 1 年储蓄率 15%→30%；3 年攒首笔 20 万可投资资产；5 年主业收入 15k→25k），每步附可选行动项。
3. **双向对照**：一边体验千万资产的开销与压力，一边看清现实路径，理性判断"到底想不想要这种人生"。

### 2.2 原始商业模式（供评估）

- 免费层：全部富人剧本 + 基础资产看板 + 简易静态对标（获客钩子）。
- 订阅会员（19 元/月、149 元/年）：高级财务模型（多情景动态测算、阶梯目标自动拆解、资产压力模拟）、多身份存档、导出 PDF、去广告、高级剧本、进度追踪。
- 一次性付费：高级剧本包 9.9~29 元；深度报告 39 元。
- B 端：企业员工财商科普、高校/图书馆采购、KOL 联名分成。
- 广告：仅非金融类（办公、学习、技能课）；严禁金融类广告。
- 明确不做：佣金分销理财/基金/保险、付费社群高额入会、售卖暴富课程。

## 3. 独立评估：真正的风险在哪

原始构想的风险清单把重点放在"合规"和"实现复杂度"上。这两点确实存在，但**不是最致命的**。以下三条才是。

### 3.1 两半产品在抢不同用户，漏斗可能从中间漏光 ⚠️ 高

- 爱玩"富人沉浸模拟"的人，要的是爽和逃离；而"看清要 47 年才够、每年税费维护费吓人"是**反爽**的。
- 真会为财务规划付费的人（对数字敏感、认真做长期计划），会觉得"扮演富豪"幼稚、羞耻，不会点进来。
- 结论：钩子人群与付费人群很可能是两拨人。这是**产品结构问题，运营补不上**。

### 3.2 最打动人的"幻觉破灭"时刻是一次性的，撑不起订阅 ⚠️ 高

- "原来维持 1000 万每年要烧这么多、原来我要攒这么久"——情绪冲击**看一次就没了**。下个月不会回来再看一遍。
- 用"进度追踪 / 每月提醒"救留存是给健身 App 套的通用件：净资产按月几乎不动，"进度"看不见，反而劝退。
- 结论：这天然是**一次性付费 / 免费引流**，不是月卡。直接证伪"19 元/月订阅"。

### 3.3 测算没有护城河——它是一道复利公式 ⚠️ 高

- "按当前储蓄速度多少年达到 X"就是复利计算，一个周末能做完，市面上一百个免费计算器。
- 壁垒只能是体验 / 内容 / 数据，但富人剧本、2D 场景、资产看板**都不构成壁垒**（游戏工作室做得更好，而你不该变成游戏公司）。
- 结论：**必须先想清楚壁垒是什么**，否则做出来就是"很好抄"的东西。

### 3.4 合规（中等，但需要从一开始就设计进去）

- 定位必须是**财商模拟教育工具**，不是投资顾问。
- 一旦给出个性化"投资建议"，即使标注"仅供教育"，也可能被认定越界。
- 安全线：**只对用户自填的假设做算术**，绝不推荐具体产品、绝不预测收益、绝不承诺结果。免责声明 + 假设透明化是底线，不是全部。

## 4. 建议方向：从"扮演富豪"转向"设计理想生活"

这是本文档的核心主张。

把"幻想层"从**扮演富豪**改成**设计你理想的生活**——住哪、开什么、每年旅行几次、要不要请人、孩子教育怎么安排。这一层依然可视化、依然有情绪，但对**所有收入水平**都成立，不只富豪。现实层则回答那句人人都有的话：

> **"要过这样的生活，我需要多少现金流？现在差多远？"**

**为什么这个转向更好：**

| 维度 | 扮演富豪（原始） | 设计理想生活（建议） |
|---|---|---|
| 受众 | 爱看爽文的人 | 所有对生活有规划的人（大得多） |
| 与付费层的匹配 | 钩子与内核互斥 | 天然一体：设计的场景直接导出数字 |
| 可重复性 | 一次性 | 人生阶段变化（换城市/买房/生娃/失业）都会回来重算 |
| 价值观风险 | "幻想暴富"信号，吸引错的人 | "多少才算够"，筛掉暴富心态 |
| 内容壁垒 | 靠剧本堆量 | 靠"生活场景 → 现金流"的模型与数据 |

**副产品洞察（可能就是真正的产品内核）：**
用户常常会发现"不需要到亿万级别，达到某个现金流水平就能实现理想生活"。这句"**多少才算够**"就是 FIRE / 财务自由那套真正的核心，也是本产品最有价值的一句话。

## 5. 商业模式判断（对原始方案的修订建议）

1. **大概率不是订阅制**，而是「免费工具 + 一次性解锁」或「一次性深度报告」。理由见 §3.2。
2. **付费点应围绕单个高赌注决策**，而不是"更多剧本 / 导出 PDF"这类弱付费墙：
   - 该不该买这套房 vs 继续租？
   - 能不能辞职 / 换城市 / 生二胎？
   - 我的退休到底长什么样？
   - 这类问题高情绪、高赌注、会被反复纠结，是真正值得付钱的时刻。
3. 原始方案的免费/付费切分里，付费项基本是"同样的东西给更多"，而非"解决一个新任务"——这是转化率杀手，建议重做。
4. 原始方案的 B 端（企业员工财商科普）值得保留，但属于中长期，不进入 MVP。
5. 广告、佣金分销等，**MVP 阶段完全不碰**。

## 6. MVP 与验证计划

**最该验证的不是"画面能不能做出来"（那是简单部分），而是"有没有人会用第二次、会不会付钱"。**

### 6.1 要测的三个数

1. **完成率**：多少人能走完"设计生活 → 看到测算"的完整流程？
2. **回访**：7 天后有没有人回来？（用最朴素的方式测复购意愿）
3. **付费**：有没有人愿意为深度报告 / 解锁付哪怕 9.9 元？

### 6.2 最小版本（先做这个，其余全部推迟）

- **一个强情绪的生活场景** + **一套测算**，尽快上线。
- 单页或极简多步表单：设计理想生活（少量关键选项，不要几十项）→ 输出"需要的现金流 / 现在差多远 / 粗略年限"。
- **不做**：3D 场景、多身份剧本、社区、B 端、账号体系（除非验证需要）。

### 6.3 明确推迟到验证之后

3D 渲染、高级剧本包、多情景推演、进度追踪、PDF 导出、社区、B 端合作——**三个数没出来之前，一律不做。**

### 6.4 实现上的注意点

- 测算模型轻量化：基础信息（收入、每月支出、存款、负债）即可出结果；精细模型作为高级选项，不要一上来就让用户填几十项。
- 所有输出强制标注假设与免责声明；模型只做用户假设下的静态推演，不做预测。
