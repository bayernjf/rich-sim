# gameplay-inventory — 玩法清单（25 个可交互玩法单元）

> 状态：2026-10-10 清点（T3 后，六通道最小版全部落地）。
> 维护纪律：**玩法有增删改时，三处必须同步**——本文档 + `apps/web/src/pages/app/guide.astro`（玩法说明页）+ `apps/web/src/lib/messages.ts` 的 `guide.*` 键（zh/en 成对，`lib/i18n.test.ts` 强制穷尽覆盖，漏键编译失败）。玩法口径 = 用户可主动交互并获得反馈的最小体验单元；纯文案页（`/privacy`）、纯系统行为（埋点、localStorage 账本、Service Worker）不计。

## 双主线定位

- **模拟主线（钩子）**：先玩一把富豪，看见财富的真实持有成本与风险。
- **现实主线（落点）**：用用户自己的收入算清「够用线 / 差距 / 年限」。
- 定位是**财商模拟教育工具**，不是投资顾问：所有数值都是对用户自填假设的算术推演，倍数与参数为教学示意，不做预测、不承诺结果。

## 全量速查（按字母序，唯一事实源）

玩法清单的唯一事实源是**玩法说明页 `/app/guide`**（运行时渲染）+ 本表。新增玩法：先加 `guide.<id>.title/.desc`（zh/en），再进 `guide.astro` 的 `STEPS` 数组，最后回写本文档。

## 红线自查（玩法层）

- 不做投资建议、不荐股、不推荐具体金融产品——只对用户自填假设做算术。
- 「可达 / 不可达 / 无净储蓄」是一等状态，不是错误分支。
- 不做记账工具、不做社交攀比社区。
- 用户自填财务数据不上传（analytics 丢 props；`fx:historical` / `guide:view` 零 props）。
- 历史汇率只做教育展示，不写进任何冻结假设。
