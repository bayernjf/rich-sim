# 新用户核心功能验证清单（浏览器 E2E 可执行）

> **用途**：以「第一次打开产品的新用户」视角，验收 rich-sim 核心功能闭环。既可人工手动走查，也可作为 agent 浏览器自动化（computer_use / headless Chrome）的执行脚本——每个验证项都给了定位钩子或按钮文案，可直接驱动断言。
> **更新时间**：2026-10-17（生产实测基线当日复核：六个路由全 200、首页领钱入口与语言切换器在线、sim 页购物/剧情/特权/来源齐全）。
> **自动冒烟**：`scripts/e2e-smoke.mjs` 已自动覆盖其中大部分（当前 238 条 FAILS 0，见 `docs/DEPLOYMENT.md`）；本清单聚焦**核心闭环**与冒烟未直接覆盖的新用户视角路径，两者互补不重复。

## 一、执行模式与前置

| 项 | 说明 |
|---|---|
| 环境 | 生产 `https://app.rich-sim.bayjf.com`（新用户看到的即此）；本地 dev :4321 同口径 |
| 干净起手 | 无痕窗口 / 清空 localStorage——不清会带上旧草稿，干扰「新用户」语义 |
| 语言 | 默认 **en**；右上角 `data-locale-switcher` 可切中文，双语断言同口径（文案不同、数字/行为一致） |
| 判定 | 动作 → 预期全命中 = **PASS**；任一预期中的金额、来源、免责缺失 = **FAIL** 并进入红线检查 |
| agent 自动化提示 | 元素定位优先用下表的 `data-*` 钩子；无钩子处用按钮可见文案（zh/en 各写一份） |

## 三、验证清单

### 阶段 0 · 打开产品（2 项）

| ID | 动作 | 定位 | 预期 |
|---|---|---|---|
| 0.1 | 访问首页 | URL `/` | 标题 `rich-sim · Wealth Simulation`；两个主 CTA：「先玩一把富豪 →」（`/app/sim`）与「用我的收入算账 →」（`/app/designer`） |
| 0.2 | 切语言 | `data-locale-switcher` → 中文 | 全站文案切中文、数字不变；刷新后语言保持 |

### 阶段 1 · ★ 钩子：领钱 + 富豪模拟（6 项）

| ID | 动作 | 定位 | 预期 |
|---|---|---|---|
| 1.1 | 首页点「Claim your first million」 | 按钮可见文案 | 出现三档虚拟起始金 **$100K / $1M / $10M**，选 $1M 领取 |
| 1.2 | 领取后进 `/app/sim` | 看板区 | 卡 A 资产结构 + 年持有成本 **$1,317,000** + 负担率 **≈78%（黄区）**；旁白解释「年账单 ÷ 现金流」 |
| 1.3 | 看「账单日」 | 账单日通道 | 收入腰斩模拟 → 负担率跳红 → 「变卖资产（折价 75%）」引导 |
| 1.4 | 切卡 B | 卡切换器 `?card=card-b` | 负担率 ≈5%（绿区），与卡 A 同一 4% 口径；`data-sim-legacy` 传承章节出现 |
| 1.5 | 商城加购一件（如超级游艇） | `data-shopping-area` → 卡 `data-item-detail` | 车件数 +1；详情卡含成本拆项（船员/停泊与保险）、**75%** 回笼、爽感档位行（`data-item-thrill`，**不出现 1–5 数字**）；每项有 Source 来源链接 |
| 1.6 | 「一键成目标」 | `data-adopt-goal` | 跳现实测算，结果页带「目标来自富豪模拟购物车」标签；REAL 只拿年成本，**无**起始金/资产占比 |

### 阶段 2 · 六通道体验（4 项）

| ID | 动作 | 定位 | 预期 |
|---|---|---|---|
| 2.1 | 剧情通道 | `data-drawn` | 三张黑天鹅卡全渲染、恰好一张抽中高亮；标注「教学示意，非预测」 |
| 2.2 | 操作通道：加杠杆 / 收购谈判 | 通道区 | 新账单 + 负担率（如 88% / 132%），给临界倍数（超 4.35× 杠杆即断裂） |
| 2.3 | 一次性价签区 | 特权通道子列表 | 「捐赠冠名 $42M」以**一次性**价签展示、标注「不是年账单」，不进购物车 |
| 2.4 | 汇率时间机 | 历史日期选择 | $1M 当年值 vs 今天 + 波动 ±%，标注「仅教育展示」 |

### 阶段 3 · ★ 落点：现实测算（6 项）

| ID | 动作 | 定位 | 预期 |
|---|---|---|---|
| 3.1 | `/app/designer` 选理想生活 | 7 维 radio 组 | 23 项可组合、每项金额带来源；切币种金额换算 |
| 3.2 | `/app/finance` 填四项 | 输入区 | 可展开「拆开填」逐项支出（住房/交通/食品/其他），任一子项填写即参与测算 |
| 3.3 | 提交 → `/app/result` | 主数字区 | 主数字「够用线」；三状态其一（可达 / 不可达 / 无净储蓄）**均为正常展示** |
| 3.4 | 关掉 JS 刷新 | SSR 源码 | 假设清单 + 免责声明仍在（纯 SSR，不被 JS 关掉） |
| 3.5 | 提取率 4%→2% | `data-assumption-input` | 够用线翻倍、年限同步变化、即时重算；`inflation` 只展示不可改 |
| 3.6 | 目标口径 / 历史 | 结果页切换器 | 「够用线 ↔ 目标净资产」可切换；再进结果页见「和上一次比」差值 |

| ID | 动作 | 预期 |

## 四、红线与判定汇总

- **红线缺陷（一票否决）**：任何金额找不到来源、出现荐股/承诺收益类表述、或隐私文案与「默认不出本机 / 登录后可选同步」口径冲突。
- **核心成立 = 阶段 1 + 3 全过**（钩子进得来、落点算得出、桥接不串账）；阶段 2/4/5 为体验层与保障层。
- 全绿出口：`TOTAL n FAILS 0`（冒烟口径）或逐项 PASS 表（本清单口径）。
