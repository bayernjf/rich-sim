# 富豪生活方式框架（wealth-lifestyle-framework）

> 状态：Draft v0.1 · 2026-10-03
> 服务对象：`PRD.md` F5 富豪模拟体验（P0，最小版）的内容骨架
> 关联：[PRD](./PRD.md) · [产品构想与评估](./product-concept.md)
> 性质说明：本框架是**模拟内容设计素材**，不是投资建议，也不构成任何财务结论。§4 的成本数字为 2026-10-03 检索到的公开区间示意，随地区、型号、年份差异很大，正式剧本建模时需按目标市场校准（见 §6）。

## 1. 一句话

把「富豪的生活方式」拆成三层可复用内容骨架：**身份来源（谁）→ 生活维度（钱花在哪）→ 风格光谱（怎么花）**，每一层都能直接映射为剧本资产、持有成本与角色性格。

## 2. 三层拆解

### 2.1 身份来源（谁算富豪）

决定资产结构、行为模式与剧本差异。

| 类型 | 典型人群 | 行为模式 |
|---|---|---|
| 新钱 | 创业者 / 明星 / 网红 | 炫耀升级快，消费跟着名气走，资产以股权与现金为主 |
| 老钱 | 继承 / 家族企业 | 低调重传承，资产藏在信托与公司架构里 |
| 职业精英 | 高管 / 顶级专业人士 | 高收入但**没有「自由」**——收入依赖持续工作 |
| 隐形富豪 | 资产不外露 | 生活方式与财富脱钩，难以从表象判断 |

### 2.2 生活维度（钱花在哪）—— 七大维度

| 维度 | 普通人幻想的样子 | 真实的样子 |
|---|---|---|
| 1 居住 | 城堡式豪宅，想住哪住哪，一栋就够 | 主宅 + 度假屋 + 城市公寓多套并行；房产税、维护、物业、安保是持续支出 |
| 2 出行 | 豪车随便买，私人飞机随叫随到 | 飞机 / 游艇都有机组、机库/停泊、保险、油、翻新的固定成本（见 §4） |
| 3 消费与收藏 | 奢侈品自由、刷卡不眨眼 | 大头是服务（管家 / 司机 / 安保）；收藏品是资产也是麻烦——要保险、鉴定、仓储 |
| 4 社交与人脉 | 被所有人围捧，去哪都贵宾待遇 | 圈子是资源交换场：俱乐部、慈善晚宴、校友会；慈善有地位与税务双重考量；社交本身是工作 |
| 5 家庭与传承 | 一掷千金给家人，全家无忧 | 教育、婚前协议、信托、家族办公室；最大焦虑从「赚钱」变成「守钱和交班」——二代败家的剧本常见 |
| 6 健康与体验 | 随心所欲、无忧无虑 | 私人医生、全球医疗、抗衰是大额支出；但压力、多线程责任、被资产绑住，并不比普通人松弛 |
| 7 时间与自由 | 不上班，环游世界 | 名义自由，日程被投资、应酬、决策填满；每架飞机每艘艇都在持续消耗现金流——**持有即开销** |

### 2.3 风格光谱（怎么花）

决定角色性格与决策倾向：

- **炫耀型**：秀资产、买地位 → 高风险、高消费
- **低调型**：不露富、防风险 → 防御性配置
- **传承型**：家族信托、守富 → 长期主义、流动性偏好
- **体验型**：买时间、买体验 → 重体验轻持有

## 3. 核心反差（产品要打的点）

幻想里「有钱 = 无限消费 + 无忧无虑」；真实里「财富是持续消耗的现金流系统 + 责任与风险」。

**持有本身就是开销**——这是富豪模拟剧本的核心叙事：资产看板 → 年持有成本 → 现金流波动（含亏损、行业下行、现金流断裂）。「幻觉破灭时刻」即：资产总额很大，但年现金流压力同样很大。

## 4. 成本数字与来源（区间示意，非承诺）

| 项 | 区间 | 口径 / 备注 | 来源 |
|---|---|---|---|
| 私人飞机年运营成本 | 约机价 5–15% | 含机组、机库、保险、油 | [The Flying Engineer](https://theflyingengineer.com/the-real-cost-of-owning-and-operating-a-private-jet/) |
| 私人飞机保险 | 机价 1–3%/年 | 与飞行员资质、用途、保额相关 | 同上 |
| 机组（2 名飞行员） | 约 25 万美元/年起 | 中型喷气级 | [NovaJet](https://www.novajet.com/knowledge-sharing/how-much-does-it-cost-maintain-private-jet-realistic-look-inside/) |
| 机库 | 7–15 万美元/年 | 视机场与气候 | 同上 |
| 超级游艇船员 | 占年运营成本 30–40% | 50 米游艇年运营约 400–600 万欧元（船员为最大单项） | [First Owner's Reference](https://firstownersreference.com/01-reality-of-ownership) |
| 游艇维护 | 船价 1–3%/年；每 5 年翻新 10–30% | 不含大修与意外 | [SuperYachtReview](https://superyachtreview.com/guides/hidden-costs-of-owning-a-superyacht) |
| 豪宅房产税（美国） | 评估值 1–2.5%/年（加州基础 1%） | 视州而定 | [Money Inc](https://moneyinc.com/the-annual-maintenance-cost-of-a-4-million-luxury-home/) |
| 豪宅维护 | 房价 1–3%/年 | 景观、泳池、结构 | [LuxCalculator](https://www.luxcalculator.com/real-estate/mansion-cost-calculator/) |
| 国内顶豪物业费 | 最高约 36 元/㎡/月，一年可达数十万元 | 上海等一线案例 | [每经网](http://www.nbd.com.cn/rss/zaker/articles/4197637.html) |

> 用法提示：以上数字只用于模拟内容的「成本感」设计，不承诺精确。正式剧本建模时按目标市场（海外 / 大陆）分别校准取值基准。

## 5. 对产品（F5 富豪模拟）的映射建议

| 框架层 | 产品映射 |
|---|---|
| 身份来源 | 剧本差异化：不同身份 → 不同资产结构与起始现金流 |
| 七大维度 | 资产类型：房产 / 机队 / 游艇 / 收藏 / 慈善与社交 / 信托与教育 / 健康 |
| 持有成本 | 资产看板的「年持有成本」计算项（月供、维护、税费、佣人、机组、船员） |
| 风格光谱 | 角色性格与决策倾向（炫耀 → 高消费高风险；低调 → 防御性配置） |
| 核心反差 | 幻觉破灭时刻：资产总额 vs 年现金流压力 |
