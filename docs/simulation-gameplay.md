## 1. 一句话主张

**购物是富豪模拟的交互引擎——每一次「购买」都是一次资产配置决策，而不是一次消费。**

价格标签是假的爽，持有成本是真的痛。这是产品差异化的核心：普通财富模拟游戏里购物=纯爽；本产品让「爽」和「代价」同时发生。

## 2. 体验机制：模拟购物与六通道

### 2.1 三类购物（对应三种「爽感 / 代价」结构）

| 类别 | 举例 | 特征 | 定位 |
|---|---|---|---|
| 资产类 | 房产 / 豪车 / 私人飞机 / 游艇 | 大额、长期、持有成本重 | 最「富豪」但最反爽 |
| 消费品类 | 奢侈品 / 收藏 / 管家等服务 | 即时满足、贬值、要维护 | 爽但烧现金流 |
| 体验类 | 旅行 / 活动 / 慈善 | 一次性、高情绪、零持有负担 | 最爽也最便宜 |

#### 爽 / 痛配比（v0.2 建议默认值，原型验证）

- **情绪极性规则**：体验类给「正爽、零持有」；消费品类「短爽、长期轻痛」；资产类「短爽、持续重痛」。目标是让用户每次买完立刻在账单上看到代价。
- **购物车配比规则（默认 1:1）**：每纳入 1 件重资产（年持有成本 ≥ 购买价 5%，或在账单里足以改变状态色），至少配 1 件体验类，避免「纯堆资产=账单地狱」或「纯买体验=没有教育点」。这里的 1:1 指**购买决策的次数**，不是金额——金额上资产类天然占绝对大头，正是要展示的反差。
- **现状缺口（需在 C2 / M3 补项）**：现有 catalog 23 个选项里几乎没有「零持有的纯体验项」（旅行维度的顶档是超级游艇这类资产），体验类爽点不足。M3 收敛购物池时需补 2–3 个纯体验项（如一次高端环球旅行、一场慈善晚宴 / 冠名、一次私人活动），其年成本为一次性消费、无持有成本。
- 情绪字段只做**相对排序**，不做伪精确打分，字段规格见 §5.2。

### 2.2 五个机制要点

1. **购物即记账**：每次购买实时写入资产负债表——现金↓、资产↑、年持有成本↑、现金流压力↑。
2. **持有成本滚雪球**：买豪宅 → 物业+税+佣人按月流出；买飞机 → 机组+机库+保险，不飞也付。界面常驻「本年度现金流：-X」，逼用户在「继续买」与「现金流断裂」之间抉择（教育时刻）。
3. **购物即剧情**：高赌注决策做成购物事件（买房 vs 继续租、买游艇 vs 存信托），对应 PRD §10 付费场景；现金流断裂触发被迫出售资产——「持有即套牢」。
4. **购物通现实**：虚拟购物车总价换算为「按我当前储蓄率要存 N 年」→ 汇入测算闭环（双主线落点）。
5. **购物车一键成为目标**：在富豪模拟里配置完的购物车，可一键设为「幻想的生活」目标，直接进入对比与阶梯目标（见 §3），无需重新设计生活。**（v0.2：已正式写入 PRD §7.2 钩子入口与 F5）**

### 2.3 其他体验通道（六通道全景）

除购物外，体验富人生活共有**六个通道**；购物属于「操作」通道的一种。每个通道都有「爽点」与「代价点」，多数可接到落点闭环（§3）。

| 通道 | 具体形式 | 爽点 | 代价点 | 阶段 |
|---|---|---|---|---|
| 看见 · 资产可视化 | 资产帝国全景（房产 / 股权 / 收藏分布）；财富仪表盘（净资产 / 现金流 / 评级） | 一眼看清「我拥有什么」 | 同时看到年持有成本总额 | MVP |
| 操作 · 决策模拟 | 模拟购物（§2.1）；投资决策；收购谈判；加杠杆 | 掌控感、权力感 | 可能爆仓、现金流断裂 | 后置 |
| 经历 · 人生剧情 | 人生快进 30 年（买房→创业→上市→退休）；随机事件（危机 / 诉讼 / 分产）；家族传承剧本 | 时间压缩的完整人生 | 黑天鹅把资产清零 | 后置 |
| 地位 · 特权体验 | 机场 VIP / 俱乐部入会 / 私人医院通道；任命高管 / 捐赠冠名 | 被世界优待 | 应酬、隐私消失 | 后置 |
| 感受 · 情绪与代价 | 账单日；失去模拟（暴跌 / 被迫出售）；时间匮乏（日程全会议） | 反差的震撼 | 直面「有钱的代价」 | MVP |
| 比较 · 落点衔接 | 对比换算器；富人账单 vs 我的账单；财富快照 | 「那我呢」的好奇 | 看清差距 | MVP |

**MVP 候选（`待定`）**：

1. **账单日**——周期性弹出「本年度要付的账单」（物业 / 税 / 机组 / 船员 / 保险），一次性划走大额现金流出，制造「持有即开销」的震撼。依赖成本模型 + 账单 UI，开发成本最低。
2. **对比换算器**——把富豪账单翻译成用户自己的单位（「他一年保险 = 我 X 年房租」），是落点闭环最顺的钩子。
3. **失去模拟**——黑天鹅事件卡（经济危机、诉讼、被迫出售），让用户亲历「持有即风险」，反爽教育内核。

**红线**：不做公开攀比 / 炫耀社交（PRD Non-Goals 已定）；地位类体验做成**私密剧情**（单人特权场景模拟），不做社交展示。

**优先级建议（`待定`）**：看见 / 感受（账单日）/ 比较（换算器）先行，经历与地位后置。

### 2.4 账单日交互设计（含 v0.2 建议默认参数）

「感受」通道的 MVP 代表，兼具「看见」属性；是购物机制的自然延伸——购物车每买一件，下一期账单就涨。

**为什么先做**：①六通道里开发成本最低（成本模型 + 账单 UI，纯前端）；②教育价值最高（直面「持有即开销」）；③天然衔接购物机制与对比闭环。

1. **触发与周期**：采用**游戏内时间轴驱动**（原方案甲）——虚拟一年压缩进会话；首次进剧本立即弹一张「年度账单」制造首轮幻觉破灭，之后每压缩一年弹一次。真实世界定期提醒（原方案乙）因 MVP 无账号 / 无推送且易成骚扰，**不采用**。
2. **账单内容**：每张账单卡 = 一项资产 × 年成本（拆到本月 / 本周）：豪宅（物业 / 税 / 佣人）、机队（机组 / 机库 / 保险）、游艇（船员 / 停泊 / 维护）、收藏（保险 / 仓储 / 鉴定）、服务（管家 / 私人教练）。口径复用框架文档 §4 与 catalog 富豪档。
3. **展示方式**：卡片堆叠逐张翻；每张带对比条「这一张 = 你现实 X 个月工资」；状态色按 §2.5 的负担率分绿 / 黄 / 红。
4. **购物车联动**：购买实时累加「下一期账单预览」；账单金额同步进资产负债表（对应 §2.2 机制 1/2）。
5. **互动**：允许变卖资产减负，但**折价**（默认 7.5 折，取原建议 7–8 折中值；教育点：资产不是原价变现）；断裂触发红色状态 + 强制变卖剧情（对应 §2.2 机制 3）。
6. **落点衔接**：账单总金额换算「相当于现实储蓄 X 年」；一键「看看我的差距」→ §3 对比闭环。
7. **开发成本**：低，纯前端（M1 技术栈内）。

**六个参数的建议默认值（v0.2，原型可回调）**：

| # | 参数 | 建议默认 | 说明 |
|---|---|---|---|
| 1 | 触发周期 | 游戏内时间轴；进剧本立即弹首次年度账单，之后每压缩一年一次 | 方案乙（现实推送）MVP 不做 |
| 2 | 翻页节奏 | 一次 **4 张**（区间 3–5），按年成本金额从高到低递进 | 先给最大冲击，再逐项叠加 |
| 3 | 「现实」参照 | 已录入收入 → 显示「= 你 X 个月工资 / 年储蓄」；未录入 → 提示录入并可跳过 | 不阻塞账单体验 |
| 4 | 变卖折价率 | **75%**（7.5 折，区间 70–80% 中值） | 资产无法原价变现 |
| 5 | 现金流断裂阈值 | 负担率 **r > 100%**（年持有成本 > 年可支配现金流） | 公式见 §2.5 |
| 6 | 状态色分界 | 绿 **r ≤ 60%** / 黄 **60% < r ≤ 100%** / 红 **r > 100%** | 公式见 §2.5 |

### 2.5 现金流负担率与断裂判定（v0.2 新增）

账单状态色与断裂判定统一用一个无量纲比率，和现实测算的口径呼应（现实线 `project()` 里「无净储蓄」= 月净 ≤ 0，语义等价于 r ≥ 100%）：

```
年持有成本合计 C = 购物车所选各项 annualCost 之和（= core scenarioAnnualCost）
年可支配现金流 CF = 角色设定的税后年收入 − 上一年已承担的年持有成本
负担率 r = C / CF
```

- **绿（可负担）**：r ≤ 60%——付完持有成本仍有 ≥40% 现金流结余。
- **黄（紧张）**：60% < r ≤ 100%——结余被压缩到 40% 以下，逼近归零，提示「再加一件可能断裂」。
- **红（断裂预警 / 已断裂）**：r > 100%——当年持有成本超过年现金流，必须变卖资产（按 75% 折价）或增加收入，否则触发强制变卖剧情。

设计意图：60% 是「安全边际」缓冲带（对应现实中不该让刚性支出占满全部收入），100% 是硬断裂线。两个阈值都是**可调设计参数**，M3 原型观察用户在哪个比率开始感到压力后再标定；实现时建议作为 `@rich-sim/core` 的命名常量（类似现有 MAX_YEARS / withdrawalRate），不硬编码进 UI。

## 3. 幻想 vs 现实 · 差距与阶梯目标

> 核心闭环已在 PRD 定稿（§6.2 核心公式、§7.1 主流程、F1–F4：设计理想生活 → 轻量录入 → 测算 → 阶梯目标）。本节约定三个设计口径，不重复需求。

1. **对比的是「可持续的现金流 / 年成本」，不是「资产总额」**——幻想生活的年成本（购物车所有持有成本之和）即够用线（= 年成本 ÷ 安全提取率，默认 4%，可调），对比用户真实年储蓄。
2. **差距给三种一等状态**：可达（X 年）、不可达（60 年内到不了）、无净储蓄（当前入不敷出）——分别给不同文案与下一步。
3. **阶梯目标数值从差距倒推、来自用户自身数据**（先提储蓄率 → 攒首笔本金 → 抬收入），不是通用模板——这是 PRD F4 的验收红线。

**增量入口（v0.2 已定稿写入 PRD §7.2）**：模拟购物车 →「把这套生活设为我的目标」→ 直接进入对比。钩子到落点一步打通；技术上即把购物车的 `LifeChoice[]` 作为 F1 设计器选择直接喂给 `scenarioAnnualCost`，无需用户重选。

## 4. 名人体验与合规路径

### 4.1 功能目标

用户选择一位「富豪」体验其生活方式，并与自己的真实财务对比（差距 → 阶梯目标）。此功能复用 §3 闭环，只是目标来源变为「富豪画像」。

### 4.2 合规风险（指名道姓不可行）⚠️

**未经同意使用真实人物的姓名、肖像、声音做商业模拟，属人格权侵权风险。** 依据《中华人民共和国民法典》：

- 第 1019 条：未经肖像权人同意，不得制作、使用、公开其肖像；
- 第 1012 / 1014 条：姓名权不得盗用、假冒；
- 第 1023 条：姓名、声音的许可使用参照肖像权保护规定；
- 第 1020 条合理使用（个人学习、艺术欣赏、课堂教学、科研、新闻报道等）**不涵盖商业模拟产品**；
- 第 1182 条：按侵权人获利赔偿——产品卖得越好赔得越多；
- 第 994 条：死者人格利益亦受保护。

另：产品「先海外」（technical-design §9），美国各州 right of publicity 对名人身份的商业利用限制更严，正式开发前需做海外法域复核（`待定`）。

**数据约束**：真实名人的年开销/持有成本没有可靠公开数据，硬做必然估算，撞项目「不编造数据」红线。

### 4.3 三条路径

| 路径 | 做法 | 结论 |
|---|---|---|
| A · 真实名人指名 | 真名 + 真形象做商业模拟 | **不建议**：人格权侵权风险 + 数据不可得 |
| B · 虚构原型角色（推荐） | 「科技独角兽创始人·千亿美元级」等原型卡；基于公开报道归纳资产结构特征，不点名、不用肖像 | **MVP 可用**：合规、数据可建模，页面标注「虚构角色，不代表任何真实人物」 |
| C · 名人授权联名 | 官方合作、授权合同 | 长期 B 端选项，不进 MVP |

### 4.4 原型卡字段与首批两张虚构卡（v0.2 定稿字段，数值为示意组合）

**字段定稿**：身份类型（框架 §2.1 四类）/ 财富量级区间 / 资产结构（占比示意）/ 年成本画像（由 catalog 富豪·理想档组合，给区间）/ 风格光谱（框架 §2.3）/ 起始年可支配现金流 CF 的设定方式。

> 共同标注：**虚构角色，不代表任何真实人物**；年成本为 catalog 选项 `annualCost`（USD/年）的直接加总，可由 `scenarioAnnualCost` 复算。catalog 全部 23 项均已附可查证公开来源（C2 已完成，2026-10；普通人/理想档锚 BLS CE 2024、AAA、KFF、NAIS、Child Care Aware、Allianz、Zillow，富豪极端档为行业公开估算），以下总额按校准后金额复算。

**卡 A · 科技独角兽创始人（新钱 / 炫耀 × 体验之间）**

- 身份：新钱，创业者；财富量级**区间**示意十亿美元级（不设单点）。
- 资产结构（示意）：公司股权为主（约 70–85%）+ 现金 / 债券 + 少量不动产；股权流动性受限。
- 年成本画像（购物车组合，USD/年）：独栋豪宅 120,000 + 私人飞机 1,000,000 + 豪华车 17,000 + 大额弹性（管家 / 司机 / 安保 / 应酬）120,000 + 私人医疗 30,000 + 高档餐饮私厨 30,000 ≈ **1,317,000 / 年**。
- **断裂教学开关**：再加一艘超级游艇（+5,400,000）→ 年成本跳到约 **6,717,000**，一张账单就把负担率打入红区，是「持有即套牢」的标准演示。
- 风格：高消费、愿为体验和地位付费，防御性配置弱。

**卡 B · 家族企业继承人（老钱 / 低调 × 传承）**

- 身份：老钱，继承 / 家族企业；财富量级区间示意数亿至数十亿美元。
- 资产结构（示意）：家族信托 + 家族企业股权为主，流动性偏好、重传承。
- 年成本画像（USD/年）：独栋豪宅 120,000（可再叠加一套城市公寓 +27,000）+ 精英寄宿 / 国际学校 100,000 + 家庭商业医保 10,000 + 高档餐饮 / 社交 30,000 + 大额弹性（管家 / 慈善 / 俱乐部）120,000 ≈ **380,000–407,000 / 年**。
- 刻意**不持有**私人飞机 / 游艇（老钱低调、重净现金流），与卡 A 形成「同级财富、不同年成本压力」的对照。
- 风格：防御性、长期主义、社交与慈善是工作而非炫耀。

> 两张卡覆盖新钱 / 老钱两极（框架 §2.1），数值只做「成本感」与教学对照；金额已随 C2 校准（2026-10），后续仅随目标市场（海外 / 大陆）与来源年度更新调整。

## 5. MVP 建议

### 5.1 购物目录：以 catalog-data 为唯一事实源，M3 收敛购物池

- **事实源**：`packages/core/src/catalog-data.ts` 现有 **7 维度 23 个选项**（USD/年），**23 项均已附可查证公开来源**（C2 已完成，2026-10；`source` 为 URL、`note` 写清口径，测试强制每个 `source` 为 http(s) 链接且金额逐维递增）。本文档不重复金额表。
- **M3 富豪购物池收敛规则**：每维度只取「理想档 + 富豪档」进入富豪购物车，剔除纯普通人锚点档（两居租房、公交通勤、自己做饭等），普通人档保留作现实对照与换算锚点。按现有 23 项收敛后约 **14–15 个可购项**；若要达到原设想的 15–20 项，缺口正是 §2.1 所说的 2–3 个纯体验项（当前目录最缺）。
- 与里程碑关系：购物机制与原型卡属于 **M3 富豪模拟（最小版）** 的内容资产；「购物车一键成目标」依赖 M1 测算闭环，属 M1–M3 之间的衔接功能（PRD §7.2 已列入口，实现随 M3）。

### 5.2 可购项的玩法字段规格（M3 在 core 类型上扩展，当前不写代码）

现有 `CatalogOption` 只有 `id / label / annualCost / source / note / isDefault`。M3 富豪购物池每项建议扩展以下**玩法字段**（结构先定，数值随内容填充与原型调，不提前编造）：

| 字段 | 含义 | 取值 / 口径 |
|---|---|---|
| `kind` | 爽痛分类 | `asset` 资产 / `consumer` 消费品 / `experience` 体验（§2.1） |
| `purchasePrice` | 一次性购买价 | 资产 / 消费品需要；体验类可为 0 或等于当年花费 |
| `annualCost` | 年持有成本（**已存在**） | 复用现有字段，即账单与够用线口径 |
| `costComponents` | 持有成本构成 | 税 / 维护 / 人员（机组·船员·管家）/ 保险 / 停泊机库 等条目或占比，口径对齐框架 §4 |
| `joy` | 购买当下情绪强度 | 1–5 相对排序，仅用于卡片呈现与配比，不参与财务计算 |
| `resellable` | 是否可变卖 | 布尔；变卖按 §2.4 参数 4 的 75% 折价 |
| `carryingJoy` | 持有期每年净情绪 | −2…+2，资产多为 0 或负、体验类无持有（N/A） |

**示例（私人飞机，字段演示，金额来自 catalog 现有项 + 框架 §4 来源）**：`kind=asset`；`annualCost=1,000,000`（来源 The Flying Engineer / NovaJet，见框架 §4）；`costComponents=` 机组约 25 万起 + 机库 7–15 万 + 保险（机价 1–3%）+ 油与维护；`joy=5`、`carryingJoy=-1`、`resellable=true`。
